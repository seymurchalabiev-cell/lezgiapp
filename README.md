# Лезги ЧIал — Модульный проект

Приложение для изучения лезгинского языка.

## Структура файлов (каждый — отдельный пазл)

```
lezgi-app/
├── index.html            ← HTML-оболочка (меняй структуру страниц)
├── css/
│   └── style.css         ← Все стили (меняй внешний вид)
├── data/
│   ├── words.js          ← Учебные слова с IPA и примерами (добавляй новые!)
│   └── dictionary.js     ← Полный словарь Гаджиева 33k слов (авто-генерируется)
└── js/
    ├── state.js          ← Хранение прогресса + SRS-алгоритм
    ├── flashcard.js      ← Режим карточек (переворот, SRS-ответы)
    ├── quiz.js           ← Режимы «выбор ответа» и «ввод»
    ├── wordlist.js       ← Экран словаря (учебные + полный словарь)
    ├── alphabet.js       ← Экран алфавита
    ├── grammar.js        ← Экран грамматики
    ├── home.js           ← Главная страница + статистика
    └── app.js            ← Запуск и навигация (подключается последним)
```

## Как открыть

Просто открой `index.html` в браузере — всё работает локально, без сервера.

## Как добавить новые слова

Открой `data/words.js` и добавь строку в массив `WORDS`:

```js
{id:'moje', lz:'мез', ipa:'[mez]', ru:'язык', cat:'тело', ex:'Мез ягъун — Говорить'},
```

- `id` — уникальный ключ (латиница, без пробелов)
- `lz` — слово на лезгинском
- `ipa` — транскрипция (можно оставить пустой строкой)
- `ru` — перевод на русский
- `cat` — категория (числа / семья / природа / тело / быт / местоим. / прилаг. / глаголы / фразы)
- `ex` — пример предложения (необязательно)

## Как пересобрать словарь

```bash
python3 build_project.py
```

Скрипт читает `Rus_lezgi_Gadjiev_txt.txt` и генерирует все файлы заново.
